About & Methodology

This demo implements a simple, explainable rule-based triage model and basic ECG signal analysis. Use these talking points when presenting:

  • Explainability: Show triage formula: R = w_symptoms*S + w_vitals*V + w_comorb*C + red_flag*W.
  • Safety: Red-flag override always sends to emergency — highlight as safety net.
  • ECG pipeline: smoothing → peak detection → RR intervals → HR & SDNN → rule flags (brady/tachy/irregular).
  • Limitations: No clinical validation, biased thresholds; emphasize need for clinician review and prospective testing.
Presentation tip: Run two demo scenarios: (1) mild cold (self-care) and (2) chest pain + shortness (emergency) — show how red flags & R change live.
